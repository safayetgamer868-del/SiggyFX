# ShiggyFX

A client-side visual customization plugin for ShiggyCord.

## Features

- Notification Customizer
- Notification background color
- Notification accent color
- Notification glow
- Message preview
- Naruto Yellow preset
- AMOLED preset
- Gold preset
- Orange preset
- PFP Effects toggle
- Custom Nameplates toggle
- Avatar Decorations toggle
- Profile Effects toggle

## Important

ShiggyFX does not unlock or bypass Discord Nitro.

It provides independent client-side visual customization.
